# Agent guide

Rolling Local is a food truck discovery project for operators and consumers.

## Read first

| Task | Start here |
| --- | --- |
| Find a project document | [Documentation index](docs/README.md) |
| Inspect the architecture or UI mockups | [MVP design reference](docs/architecture.md) |
| Work on MVP scope or Ahara hosting | [Backlog](docs/backlog.md) |
| Record an architectural decision | [Architecture decision records](docs/adr/README.md) |

## Documentation

- Follow the product repository conventions in `../ahara/skills/repo-docs/SKILL.md`, relative to the repository root.
- Keep entry files short. Put implemented behavior in topical docs, planned work in the backlog, architectural decisions and their rationale in ADRs, and shipped changes in the changelog.
- When the Arconis reference changes, regenerate the PNG from the editable file and check both the architecture and UI mockups in the result.
- Before implementing hosting, read the applicable sections of `../ahara/INTEGRATION.md` and `../ahara/CI-WORKFLOW.md` from the repository root.
